Why this works
Safari on iPadOS exposes the Apple Pencil through the standard Pointer Events API — a pen pointer type plus live pressure and tilt. No native app and no plugin: a plain web page reads them directly. If the pencil drew above, our reveal.js decks can carry the same live annotations.
